Step 3:

1. In Render, log in with your GitHub account.
2. Go to the dashboard.
3. Click +Create new project.
4. Enter your project name, for example: my-devdeploy-project.
5. Click +Create new service.
6. Click Web Services.
7. Select your project.
8. Configure and deploy the service:
   - Add a service name, for example: my-devdeploy-web.
   - Scroll down and add the Start Command, for example: npm run dev.
   - Select $0 / month, 0.1 CPU, 512 MB RAM, Free.
   - Scroll down and add Environment Variables if your app uses an API. Enter each variable name and value, for example: API_URL, https://api.example.com.
   - Click Deploy web service.
9. After deployment, click Manual Deploy in the top right.

Keep private passwords and API keys in Render Environment Variables instead of committing them to GitHub.
