Step 2:

How to Connect Your Code to GitHub

1. Create a repository on GitHub.
   - Go to https://github.com
   - Sign in or create an account.
   - Click the + button in the top-right corner.
   - Choose New repository.
   - Give the repository a name.
   - Choose Public or Private.
   - Do not add a README if your project files already exist locally.
   - Click Create repository.

2. Open PowerShell or Command Prompt and move into your project folder:

   cd "C:\path\to\your\project"

3. Initialize Git in the project folder:

   git init

4. Stage all files for the first commit:

   git add .

5. Create the first commit:

   git commit -m "Initial commit"

6. Link your local repository to the GitHub repository:

   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git

7. Rename the default branch to main:

   git branch -M main

8. Push your code to GitHub:

   git push -u origin main

9. Refresh your GitHub repository page. Your files should now appear in the remote repository.

Useful commands for future updates:

   git add .
   git commit -m "Describe your changes"
   git push

Important:
- Never upload passwords, API keys, or secret files.
- Add sensitive files to a .gitignore file before running git add .
- GitHub may ask you to sign in through your browser when you push.
