Step 1:

How to Install Git on Windows

1. Open a browser and go to the official Git downloads page:
   https://git-scm.com/download/win

2. Select the Windows download option.
   Git for Windows usually offers the latest x64 installer for standard PCs.

3. Download the installer and open it.

4. Follow the installation wizard:
   - Accept the license agreement.
   - Keep the default install location unless you have a reason to change it.
   - Keep the recommended options selected.
   - Click Install.

5. Finish the setup wizard.

6. Open PowerShell or Command Prompt.

7. Confirm Git was installed:

   git --version

8. You should see a version string similar to:

   git version 2.55.0.windows.3

Git is now installed and ready to use.
